# Rats! — Win11 Revival

<b>简体中文</b> ｜ <a href="README.en.md">English</a>

把 **Rats!**（1996）复活到现代 Windows 11，附带可自由选 1~40 关的图形选关器。

> **Rats!** 是 Sean O'Connor 1996 年出品的免费 Windows 策略小游戏：
> 玩家在迷宫里放置炸弹、毒气、放射性废物、性别转换药水等道具，
> 赶在老鼠繁殖成灾之前把它们全部消灭。原版按钮区域有一个
> **命中测试缺陷**，导致后三章的菜单按钮点了没反应。

## 快速开始

```
双击 Rats.exe        # 直接开始玩
双击 选关器.bat      # 打开选关器（自由选关 1~40 关）
```

> 没有 Python 环境时可运行 `python 选关器.py`（需 Python 3）。
> 选关器会先杀掉已运行的 Rats.exe，再自动启动游戏并等待主窗口出现，
> 在「关卡」输入框里填 1~40，点「跳到该关」即可。

## 修复内容

| # | 问题 | 修复 | 状态 |
|---|---|---|---|
| 1 | **后三章按钮点不动**：主菜单按钮命中测试有缺陷（`i` 从不递增，整段无循环），后三章（第 2/3/4 章）按钮点击无效 | 选关器绕过命中测试，直接发 `WM_COMMAND(0xD2 + i)` | ✅ |
| 2 | **试玩限制卡住后三章**：游戏是 30 关免费版（`DLG_DEMO`），原版在「通关计数器 > 7 且 当前关卡索引 >= 9」时弹试玩结束框，导致后三章过关后进不了下一关 | 修改 `Rats.exe` 的判断阈值（9 → 99）根治，选关器无需内存处理 | ✅ |
| 3 | **无选关机制**：章节切换代码把关卡索引写死成每章第一关（0/10/20/30） | 选关器运行时改写对应分支的 imm32 立即数，实现任意跳关（1~40），跳完还原 | ✅ |

## 选关器原理

游戏主菜单的按钮命中测试有缺陷，但**章节切换的实际执行代码是完整的**：
章节切换的四个分支把关卡索引写死成每章第一关：

```
0x40983C  mov [0x4199A8], 0     ; 第1章 -> 第1关
0x409868  mov [0x4199A8], 0xA   ; 第2章 -> 第11关
0x409894  mov [0x4199A8], 0x14  ; 第3章 -> 第21关
0x4098C0  mov [0x4199A8], 0x1E  ; 第4章 -> 第31关
```

选关器 `选关器.py` 的做法：

1. 找到对应章节分支里 `mov [0x4199A8], imm32` 的立即数地址
2. 用 `VirtualProtectEx` 临时放开代码段写保护，`WriteProcessMemory` 把立即数改成目标关卡索引
3. 发 `WM_COMMAND(0xD2 + chap)`，让游戏主线程自己加载关卡——无需注入、无线程安全问题
4. 跳完把立即数还原成原值，避免影响游戏内菜单

关键地址：

| 地址 | 含义 |
|---|---|
| `[0x415570]` | 真正加载的关卡（-1 = 未加载） |
| `[0x4199A8]` | 章节索引 |
| `[0x4199A4]` | 章节号位掩码（1 / 2 / 4 / 8） |
| `[0x4199C4]` | 已购解锁标志 |

> 注意：关卡加载函数 `0x40A884` 会把 `[0x4199C4]` 清零，而章节切换门控要求它 = 1，
> 所以每次跳关前选关器都会先补写 `C4=1`。
